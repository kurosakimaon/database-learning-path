〇、开场：先把一件事想明白

很多人用了三年数据库，仍把它当"一个能存东西的黑盒"。这门课第一天就要把它拆开： DBMS 是一个和你平级的独立软件。你发一句 SQL，它内部要走 解析器 → 重写器 → 优化器 → 执行器 → Buffer Pool → 索引 → 锁 → 磁盘页。 这一长串东西，本质上全是你熟悉的那类代码：循环、指针、缓存、锁、日志。

老师傅的话

数据库的全部设计，都在调和同一对矛盾：磁盘按页读写且慢得离谱，内存快十万倍却一断电就没。 你后面要学的 B+ 树、Buffer Pool、WAL、MVCC、LSM-Tree，一个都没逃出这个圈。 记住这句话，学原理就不会迷路。

矛盾一 · 空间
数据放不进内存
于是有了页、B+ 树、扇出、Buffer Pool、局部性——第 2 关。
矛盾二 · 时间
写一半时断电了
于是有了 WAL、undo/redo、checkpoint、崩溃恢复——第 3、5、7 关。
矛盾三 · 并发
一千个人同时改同一行
于是有了锁、隔离级别、MVCC、死锁检测——第 3 关。

用你已有的 C++ 直觉去理解它

这张对照表是这门课的翻译器。遇到新概念，先回这里找它的 C++ 原型。

数据库概念你熟悉的 C++ 对应物差在哪（这才是要点）
表 / 行std::vector<Row> 行要序列化进定长页，长度可变，还得能定位单条
聚簇索引数据本身就 std::map 式有序存放 一棵树只能有一种物理序，所以一张表只有一个
二级索引std::map<Key, std::vector<RID>> value 是"地址"不是数据，取全行要回表
Buffer Pool带淘汰策略的对象缓存池 淘汰单位是页；脏页被踢前必须写回，否则丢数据
WAL / redo log先写 journal 再改主数据，最后 fsync 顺序写换随机写；commit 只等日志，不等数据页
行锁按 key 分片的 std::mutex 池 要排队、要超时、要做等待图找环（死锁检测）
MVCC写时复制 + 快照迭代器 读不加锁；代价是版本链、清理与"旧版本可见性"规则
LSM-Treestd::map 攒批 → 归并排序落盘 → 多层合并 写换读：写放大/读放大/空间放大三者互相牵制

💎 内功期 · 存储引擎与索引

最重要的一关 进入本关 →

数据库的"内存模型"。这里想通了，后面所有性能问题都能自己推出来；想不通，优化永远是玄学。

  • 01_disk_and_page.cpp亲手实现 4KB 定长页 + Pager + LRU Buffer Pool，打印每一次磁盘读写
  • 02_btree_vs_sorted_array.cpp100 万 key 四方案对决：线性 / 二分 / B+ 树 / 红黑树，分开算 CPU 账和 I/O 账

实测结论：比较次数会骗人，页读取次数才是分水岭——100 万 key 时二分要 20 次随机 I/O，B+ 树只要 4 次（树高）； 扇出 101 时千万级数据树高仍只有 4、5 层。

🔥 心法期 · 事务与 ACID

数据库的并发编程 进入本关 →

你写过 std::mutex，但你写过"带超时、要检测死锁、还得能被回滚"的锁吗？ 这一关不靠背表格，靠两个线程真的把数据搞坏给你看。

  • 01_acid_in_sqlite.sqlBEGIN/COMMIT/ROLLBACK、SAVEPOINT 部分回滚、WAL 模式、约束兜一致性
  • 02_transaction_raii.cppRAII 事务（异常自动回滚）+ SQLITE_BUSY 重试策略
  • 03_isolation_anomaly_lab.cpp多线程带毫秒时间线，复现脏读 / 不可重复读 / 丢失更新，再给两种修法
  • 04_lock_and_deadlock.cpp手搓行锁管理器：共享/排他、等待队列、超时、等待图找环破死锁
  • acid_cheatsheet.md一页速查：ACID 各靠哪个机制、隔离级别对照、死锁排查套路
  • mvcc_animator.html【动画】版本链 + read view，切 RC/RR 看快照时机差别与"命中哪个版本"
  • isolation_playground.html【动画】双事务逐步执行，出现脏读时明确亮徽标并解释；三种隔离级别切换
关键认知：ACID 不是四兄弟，是分工——原子性靠 undo log，持久性靠 redo log + fsync， 隔离性靠锁 + MVCC，一致性是前三者加业务约束的共同结果。

👑 化境期 · 查询处理器内幕

优化器是个会计 进入本关 →

优化器不懂真理，它只信统计信息和代价公式。理解这一点，你就再也不会问"为什么不走索引"这种问题了。

🏆 大师期 · 手搓迷你数据库 miniDB

毕业设计 进入本关 →

六个阶段，每阶段一个可独立编译运行的程序。写完它，数据库对你不再是黑盒—— 因为你亲手踩过 B+ 树分裂丢条目、也亲手把撕裂的 WAL 截干净。

  • phase1_pager.cpp4KB 定长页 + 元数据页 + LRU 页缓存，打印命中率与磁盘读写次数
  • phase2_heap_table.cppRID=(page,slot)、变长行格式（列偏移表 + null bitmap）、slot 复用，万行读写
  • phase3_btree_index.cpp落盘 B+ 树二级索引：两种页格式、叶子双向链表、插入分裂、范围扫描
  • phase4_wal.cpp预写日志 + 崩溃恢复：撕裂页 / 提交前崩 / 提交后崩三场景真注入
  • phase5_sql_frontend.cpptokenizer + 递归下降解析器 + 选择/投影算子 + EXPLAIN 输出选没走索引
  • phase6_bench.cpp汇总基准，并与真 SQLite 20 万行对照，差距如实打印并解释
本机实测数字：B+ 树点查比全表扫描快 756 倍、范围查快 20770 倍（树高 2、5 万条、命中率 100%）； 三种崩溃场景全部恢复成功且全表总和守恒；写吞吐 SQLite 仍比我们快 1.5 倍——差距在哪，phase6 注释里逐条写清了。

三、环境与命令

你的机器已具备全部条件：MSYS2 UCRT64 的 g++ 15.2、sqlite3 3.51（含开发头文件与静态库）。 没有 CMake，也不需要——所有示例刻意做成单文件，直接 g++ 就能编译。 

# 1) 跑 SQL 剧本（内存库，不留文件）
C:\> sqlite3 ":memory:" ".read fundamentals\01_sql_tour.sql"

# 2) 开个交互式 sqlite 玩索引
C:\> sqlite3 学习库.db
sqlite> .read storage_index\03_index_in_practice.sql
sqlite> .tables
sqlite> .schema loans

# 3) 编译 C++ 示例（不需要 SQLite 的）
C:\> g++ -std=c++17 -O2 -Wall -Wextra storage_index\02_btree_vs_sorted_array.cpp -o demo.exe
C:\> .\demo.exe

# 4) 需要链 SQLite 的（第 1、3、4 关与 minidb phase6）
C:\> g++ -std=c++17 -O2 cpp_integration\01_sqlite_c_api.cpp -o demo.exe -lsqlite3

# 5) 动画页面无需任何服务，双击 HTML 即可（零外部依赖、可离线）
三个环境坑

① SQLite 外键默认关闭，每个新连接都要 PRAGMA foreign_keys = ON;，否则非法数据悄悄插进去， 你会误以为外键没用（它是连接级、不是库级）。 ② fundamentals/02_schema_design.sql 和 transactions/01_acid_in_sqlite.sql 跑完退出码是 1，那是刻意制造的约束冲突与锁冲突演示，不是文件坏了。 ③ 程序里生成的 .db / .exe 用完自己删，别留在库里。

四、怎么学才算学会了

  1. 每关先跑再读。把示例编译跑起来，看输出，再回头读注释。倒过来就成了看小说。
  2. 动画要先猜再看。比如 B+ 树动画：先自己在纸上预测插入 30、40 后树长成什么样，再点"插入"验证。猜错的那次才是学习发生的时刻。
  3. 每关的 tutorial.md 末尾有课后练习，必须动手。只做到"看懂"，一周后剩三成。
  4. 用输出数字校准直觉。别信"看起来对"，信退出码、信你亲手打出来的数字——这是这门课反复验证的一条。
  5. 最后一定要自己写 minidb，而不是读它。建议每阶段先只读需求说明，自己实现，卡住 30 分钟以上再对照参考实现。

五、通关之后

老师傅的话

数据库是计算机科学里少数"理论彻底落进工程"的地方。B+ 树在课本上是练习题， 在这里是三万倍的性能差；WAL 在课本上是两行定义，在这里是断电后你的钱还在不在。 你现在已经知道它们每一个字节是怎么排的了——往后遇到任何数据库， MySQL、PostgreSQL、RocksDB、TiDB，你看到的都是熟悉的老朋友。

想再往上走，三条路：《Database System Concepts》补理论体系； CMU 15-445 公开课 + 它的 Project 4 把并发控制做扎实； 或者直接去读 SQLite 源码——它是这个星球上最值得我们这种人读的工程杰作， 单文件、注释极好、你前面七关学的东西在里面一一对得上号。
