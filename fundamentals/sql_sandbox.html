🧪 SQL 沙盒 · 手写的迷你 SQL 求值器

这里没有 SQLite，只有一份静态数据和一段纯 JS 写的"迷你查询引擎"。 你自己就是数据库——它老老实实一行一行扫，所以「扫描行数」永远等于全表行数。

支持的语法：
SELECT 列 | * | 列 AS 别名
FROM 表
WHERE 支持 = != <> > >= < <= AND OR NOT、 LIKE（% 和 _）、IS [NOT] NULL、IN (...)、括号
ORDER BY 列 [ASC|DESC] [, ...]
LIMIT n [OFFSET m]
